# PaperRoute · 本地复刻（学习研究用）

一个基于 **Vite + Three.js** 的 3D 网页送报游戏，复刻自 [paperroute.lol](https://paperroute.lol/)（原作者 [@BuiltBySketch](https://x.com/BuiltBySketch)）。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 http://localhost:5173）。

## 操作

| 按键 | 动作 |
| --- | --- |
| ← / → | 左右转向 |
| ↑ / ↓ | 加速 / 刹车 |
| 空格 / 点击屏幕 | 投递报纸（点击左/右半屏指定投递侧） |

## 玩法

- 把报纸投进**亮灯的订户邮箱**得分，连续投递有连击加成（最高 ×5）
- 投错房子、错过订户、撞坑洼/垃圾桶/被狗咬都会受罚，共 3 条命
- 对已服务过的房子再次投掷会**砸窗户**：非订户 +400（恶作剧奖励），订户则流失
- 骑到终点横幅结算，按投递率评级 S/A/B/C

## 技术要点

- 弧形街道中心线 + 带状几何（路面/人行道/路缘沿曲线生成）
- 房屋 GLB 实例化 + 种子化变色，水粉罩染着色器（`onBeforeCompile`）模拟手绘质感
- 等距全景天空 + 远景小镇环幕 + 交叉面片手绘树木
- WebAudio 实时合成音效（投掷/投递/撞车/狗叫等，参数参考原作）+ 采样玻璃碎裂音
- 确定性随机种子生成街区布局

## 目录结构

```
game/
├── public/art/      # 房屋/骑手/狗模型与手绘贴图（原作素材，见上方声明）
├── public/audio/    # 背景音乐与玻璃音效（同上）
├── src/
│   ├── main.js      # 启动、天空、灯光、相机、主循环
│   ├── config.js    # 路线/规则常量、弧形中心线
│   ├── street.js    # 街道生成（路面/房屋/邮箱/障碍/横幅）
│   ├── assets.js    # GLB 加载与实例化（素材接口层）
│   ├── paint.js     # 水粉罩染着色器
│   ├── rider.js     # 骑手与狗
│   ├── game.js      # 玩法逻辑（投递/砸窗/障碍/狗）
│   ├── sound.js     # WebAudio 合成音效 + 采样
│   └── hud.js       # HUD、开场/结算报纸
└── tools/shot.mjs   # 无头浏览器截图验证工具
```
